## Strategic priorities

1. **A useful first sortie.** Homepage and public enlistment guidance should direct a new pilot toward one manageable activity. More choices are not a substitute for a clear start. Skill-qualified hulls, ordinary-agent access, replaceable losses and in-game site checks matter more than the highest mission level.
2. **Profitable participation.** Earn site LP and build useful contribution while managing losses; winning is valuable but not an unconditional primary objective. Actual site availability, opposition, replacement cost, travel and LP conversion all influence a pilot's best choice. Unknown data must stay unknown.
3. **Real shared activity.** Posted fleets, paid supply jobs, verified progress and authentic reports create stronger return value than cosmetic achievements. Cozen can benefit by organizing reliable opportunities without making corporation membership a requirement for the tools.
4. **A reason to revisit, without chores.** New campaigns, actual operations, changing stock and approved transmissions provide natural return triggers. Completed goals should reveal another attainable goal; avoid mandatory daily tasks, artificial urgency and fabricated community activity.
5. **Story as an extension of EVE.** Plain RP language, portraits, public lore and optional stories add identity. Tools should remain readable and truthful. Site achievements must remain clearly distinct from in-game records.
